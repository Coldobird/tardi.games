# Texture sources

## Review-only Paper Mario reference

The following background textures are copied from Nintendo's official [Paper Mario: The Origami King page](https://www.nintendo.com/au/games/nintendo-switch/paper-mario-the-origami-king/) for the current visual prototype. They are not cleared for production use and should be replaced or separately licensed before shipping.

## Font

- `lilita-one-regular.ttf`: [Lilita One](https://github.com/google/fonts/tree/main/ofl/lilitaone), Google Fonts, SIL Open Font License 1.1. The bundled license is `LILITA_ONE_LICENSE.txt`.

## UI reference

- The light notebook palette and cut-paper control treatment were informed by [Snipperclips UI references](https://gameuidatabase.com/gameData.php?id=1443). No Snipperclips artwork is bundled. `notebook-doodles.svg` is an original decorative pattern for DecoDoodle.
